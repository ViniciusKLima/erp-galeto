# Skill — Configurações

## Categorias

Categorias devem possuir:
- nome;
- tipo;
- ativo/inativo.

Uma categoria de Receita não deve aparecer para uma Despesa.

## Subcategorias

Subcategoria pertence a uma categoria.

Ao selecionar uma categoria:
→ listar somente suas subcategorias ativas.

## Contas financeiras

Permitir:
- criar;
- editar;
- ativar/desativar;
- consultar saldo;
- definir saldo inicial.

Não permitir apagar fisicamente uma conta que tenha histórico financeiro sem tratamento adequado.

## Formas de pagamento

Permitir cadastro e ativação/desativação.

## Configuração

Evitar transformar toda regra do sistema em configuração.

Regras fundamentais devem permanecer no domínio/aplicação.
