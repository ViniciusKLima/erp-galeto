# Skill — UX/UI

## Princípios

- simples;
- direto;
- consistente;
- responsivo;
- profissional;
- poucos cliques para operações frequentes.

## Dashboard

Priorizar leitura rápida:
1. situação financeira;
2. evolução;
3. composição;
4. pendências.

## Formulários

Utilizar:
- campos condicionais;
- máscaras monetárias;
- feedback de validação;
- confirmação para ações destrutivas;
- estados de carregamento.

## Tabelas

Devem possuir:
- busca;
- filtros;
- ordenação;
- paginação quando necessário;
- ações claras.

## Cores

Não usar cores apenas como decoração.

Status devem possuir representação textual além de cor.

## Responsividade

Desktop é importante para gestão, mas operações básicas devem funcionar em telas menores.
